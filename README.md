# Explainable AI for Loan Approval Prediction

## Overview
This project builds a machine learning model to predict loan approval and explains the decision-making process using SHAP.

## Features
- Data preprocessing
- Model comparison
- Random Forest training
- Model evaluation
- SHAP-based explainability

## Technologies Used
- Python
- Scikit-learn
- SHAP
- Pandas
- Matplotlib

## Results
The model achieved approximately 90% accuracy in predicting loan approval decisions.

SHAP analysis revealed that credit history and applicant income are among the most influential features.
